## ⌨️ Quick Start

### Open Workspace
```
File → Open Folder → Select directory
```

### Create File
```
Right-click folder → New File → Enter name
```

### Edit Code
```
Double-click file → Edit with highlighting
```

### Run Project
```
Click Run button (F5) → View output
```

### Use Terminal
```
Ctrl+` → Type command → Enter
```

## 🚀 Getting Started

### Installation
1. Ensure Python 3.x and PySide6 installed
2. Clone/download MyCodingMaster
3. Run `python main.py`

### First Use
1. **Open Workspace**: File → Open Folder
2. **Explore Files**: View in Explorer panel
3. **Edit Code**: Double-click any file
4. **Run Project**: Click Run button (F5)
5. **Use Terminal**: Press Ctrl+`

### Tips
- Pin frequently used workspaces
- Use keyboard shortcuts for speed
- Right-click in Explorer for file operations
- Use terminal for command-line tasks
- Session auto-saves on close
