# Explorer Visibility Fix - Test Plan

## Root Cause
The bug was caused by improper use of `setFixedWidth()` which locks both minimumWidth and maximumWidth to the same value, preventing proper animation cycles.

## Solution
Replaced all `setFixedWidth()` calls with separate `setMinimumWidth()` and `setMaximumWidth()` management:
- During hide: animate both to 0
- During show: animate both to target, then unlock max to allow resizing
- During manual resize: lock during drag, unlock after drag ends
